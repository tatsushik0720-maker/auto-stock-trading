# 株の架空売買シミュレータ

日足データで売買ルールを検証するための**架空**売買シミュレータです。
実際の注文や証券口座への接続は一切行いません。

## 使い方

```bash
pip install -r requirements.txt
python run.py                    # config.yaml の設定で実行
python run.py --fee-rate 0.001   # 手数料だけ 0.1% にして比較（ファイルは書き換えない）
python -m pytest                 # テスト
```

銘柄・資金・期間・戦略は **`config.yaml` だけ**を書き換えて変更します。

## 進み具合

- [x] 段階1: 土台（設定ファイルの読み込みと入力チェック）
- [x] 段階2: データ取得（yfinance と `data/` へのキャッシュ）
- [ ] 段階3: 戦略（1戦略1ファイル。最初は25日移動平均）
- [ ] 段階4: シミュレータ（手数料・値差・税・積立・日次記録）
- [ ] 段階5: 評価（損益・最大ドローダウン・買って放置との比較）

## データについて

- 取得した日足は `data/銘柄.csv` に保存し、次回からは足りない分だけ取得します。
- ネットにつながらないときは、保存済みデータで続けます（警告が出ます）。
- Yahoo のデータには、株式分割の直後だけ価格が 1/10・1/100 のまま入っている誤りが
  見つかっています（1321.T: 2026-10-05〜06、1306.T: 2026-03-30〜31）。
  読み込み時に自動で直し、直した内容を表示します。
- 売買単位は JPX「銘柄一覧（ETF）」の Trading Unit 欄で確認できます。

## フォルダ構成

```
config.yaml        設定（ここだけ触る）
run.py             実行入口
src/sim/           本体（config.py など）
tests/             テスト（ネット接続不要）
data/  output/     取得データと結果（git管理外）
```
